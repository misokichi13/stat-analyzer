# stat-analyzer（CSVアンケート集計ツール）

CSV形式のアンケート結果を読み込んで、基本集計・クロス集計を行うブラウザツールです。データはブラウザ内でのみ処理され、外部に送信されません（AI分析用のプロンプト生成機能を除く）。

公開URL: https://misokichi13.github.io/stat-analyzer/

## できること
- 基本集計（単一回答・複数回答（0/1方式）に対応、無回答を区別）
- クロス集計とカイ二乗検定（期待度数が小さいセルの警告つき。複数回答が絡む場合は検定を行いません）
- グラフ表示、印刷用レイアウト
- Geminiに渡すための分析プロンプトの生成

## 使い方
1. ページを開き、CSVファイルを読み込む（文字コードはUTF-8前提です。Excelから出す場合は「CSV UTF-8」で保存してください）
2. 集計したい項目を選び、出力対象に追加する
3. クロス集計は行・列の項目を選んで実行

## 構成
- index.html … 画面
- css/style.css … スタイル
- js/stats.js … 統計計算
- js/app.js … 画面と集計の制御

## 注意
- 統計ライブラリ（jStat・PapaParse・Chart.js）はCDNから読み込みます。jStatが読み込めなかった場合、カイ二乗検定のp値は「計算できませんでした」と表示されます。
